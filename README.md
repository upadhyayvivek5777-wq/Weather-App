🌦️ Weather App

A modern and responsive Weather App built using HTML, CSS, and JavaScript. This project provides a clean and attractive user interface where users can search for weather information and view essential weather details in a visually appealing layout. The design focuses on simplicity, responsiveness, and user experience with a modern glassmorphism-inspired interface. Weather apps commonly provide city-based weather lookup, temperature, humidity, and wind information, which are core features of this type of project.
