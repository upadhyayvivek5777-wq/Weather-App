# 🌦️ Weather App

A modern and responsive Weather App built using **HTML, CSS, and JavaScript**. This project provides a clean and attractive user interface where users can search weather information and view important weather details in a visually appealing layout.

## 📸 Preview

A beautiful weather application with:

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature display
- 💧 Humidity information
- 🌬️ Wind speed details
- 📱 Fully responsive design
- 🎨 Attractive UI/UX
- ⚡ Fast and lightweight

- HTML5
